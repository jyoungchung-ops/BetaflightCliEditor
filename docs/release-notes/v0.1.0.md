Betaflight 기체의 CLI 설정을 USB로 읽어 Betaflight App(구 Configurator)과 비슷한 탭 화면으로 보여 주는 **읽기 전용** Windows 앱입니다. FC에 아무것도 쓰지 않습니다.

## 받을 파일

| 파일 | 용도 |
| --- | --- |
| `FC-CLI-Viewer-Setup-0.1.0.exe` | **설치판** — 시작 메뉴·바탕화면 바로가기를 만들고, 제어판에서 제거할 수 있습니다 |
| `FC-CLI-Viewer-0.1.0-portable.exe` | **휴대용** — 설치 없이 바로 실행합니다 (USB 메모리에 넣고 다니기 좋음) |

Windows 10/11 64비트에서 동작합니다. Node.js나 브라우저를 따로 설치할 필요는 없습니다. 아래 Assets에서 둘 중 하나만 받으면 됩니다.

## 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면

코드 서명 인증서가 없어서 Microsoft SmartScreen이 "인식할 수 없는 앱" 경고를 띄웁니다.

1. 경고 창에서 **추가 정보**를 누릅니다.
2. 아래에 나타나는 **실행** 버튼을 누릅니다.

같은 파일로는 다시 묻지 않습니다. 브라우저가 다운로드를 막으면(예: Chrome "흔히 다운로드되는 파일이 아닙니다") 다운로드 목록에서 **유지**를 선택하세요.

## 사용법

1. **Betaflight App을 닫습니다.** 같은 COM 포트를 두 프로그램이 함께 쓸 수 없습니다.
2. 기체를 USB로 연결합니다. 프로펠러는 빼고, 배터리 없이 USB 전원만으로 충분합니다.
3. 앱 첫 화면에서 COM 포트를 고릅니다. STM32·AT32 장치는 **"(FC 추정)"** 으로 맨 위에 나옵니다.
4. **기체 연결** → 기체 이름을 입력합니다. FC에 저장된 이름이 기본값으로 들어갑니다.
5. **읽기 시작** → 10~30초 뒤 설정 탭이 열립니다.
   - 설정 · 포트 · 구성 · 전원 · 페일세이프 · PID 튜닝 · 수신기 · 모드 · OSD · VTX · LED · 블랙박스 · GPS · CLI 등 18개 탭
   - 기본값과 다른 값은 **노란 점·노란 테두리**로 표시됩니다
   - 레이트는 Actual 방식 값(중앙 감도 / 최대 레이트 °/s / 엑스포)으로 보여 줍니다
6. 읽기가 끝나면 **기체 USB를 뽑았다 다시 꽂으세요.** FC가 CLI 모드에 남아 있어서, 다시 꽂아야 정상 상태로 돌아옵니다.
7. 상단 바의 **저장**으로 `<기체이름>.bfview.json` 파일을 만듭니다. 처음에는 `문서\FPV 기체` 폴더를 제안합니다.
8. 나중에 첫 화면의 **저장 파일 열기**나 창에 끌어다 놓기로 기체 없이 다시 볼 수 있습니다. Betaflight App CLI 탭에서 저장한 `diff all` / `dump all` `.txt` 파일도 열립니다.
9. **원문 내보내기**는 `diff all` 원문을 `<기체이름>_diff.txt`로 저장합니다. Betaflight CLI에 그대로 붙여넣을 수 있는 형식입니다.

## 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| COM 포트가 안 보임 | 충전 전용이 아닌 **데이터용 USB 케이블**인지, 장치 관리자 "포트(COM & LPT)"에 기체가 보이는지 |
| "다른 프로그램이 포트를 사용 중" | Betaflight App 등 COM 포트를 연 프로그램을 닫고 다시 시도 |
| "CLI 모드로 들어가지 못했습니다" | 기체 USB를 뽑았다 다시 꽂고 다시 시도 |

## 지원 펌웨어

Betaflight 4.5.x, 2025.12.x 형식을 읽습니다(실기체 확인: 4.5.3, 2025.12.2). 2025.12에서 바뀐 항목(serial 포트 이름, D / D Max 의미 변경, `failsafe_landing_time`, GPS 레스큐의 오토파일럿 설정 등)도 버전에 맞게 표시합니다.

이 앱은 Betaflight 프로젝트와 관련이 없는 개인 도구입니다. 앱이 FC로 보내는 명령은 `#`, `version`, `status`, `diff all`, `dump all`, `get` 뿐입니다.
