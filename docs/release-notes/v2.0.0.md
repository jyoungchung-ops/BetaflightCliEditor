**Betaflight CLI Editor 2.0.0** — v1(FC CLI Viewer 0.1.x)의 보기 기능에 **편집 · 내보내기 · 기체에 쓰기**를 더했습니다. Betaflight 공식 프로그램이 아닙니다.

> ⚠️ **기체에 쓰기는 프로펠러와 배터리를 분리하고 USB로만 연결한 상태에서 하세요.** 쓰기 기능은 Betaflight SITL(4.5.3 · 4.5.5 · 2025.12.5 · 2026.6.2)에서 오류 주입까지 시험했고, 실제 기체(Meteor75 Pro, 4.5.3)에서 쓰기·재검증을 확인했습니다. 다른 기체에서는 시험 중입니다. 처음에는 `craft_name` 같은 비행과 상관없는 값 하나로 쓰기 → 확인 → [백업으로 되돌리기]를 해 보세요.

## 받을 파일

| 파일 | 용도 |
| --- | --- |
| `Betaflight-CLI-Editor-Setup-2.0.0.exe` | **설치판** — 시작 메뉴·바탕화면 바로가기, 제어판에서 제거 |
| `Betaflight-CLI-Editor-Portable-2.0.0.exe` | **휴대용** — 설치 없이 실행 |

Windows 10/11 64비트. v1(FC CLI Viewer)과 나란히 설치할 수 있습니다.

처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요(코드 서명 인증서가 없어서 나오는 경고입니다).

## 새 기능

- **편집 모드** — 상단 바 [편집]. 숫자·목록·켜짐/꺼짐 입력, 모드(AUX) 범위 끌기·추가·삭제, 포트 기능 체크, OSD 요소 끌기·프로필별 표시, 채널 맵, 페일세이프 채널 값.
  - 기체에서 읽은 `get` 범위로 바로 검사(범위 밖 = 빨간 테두리), 바뀐 값은 파란 테두리, 탭별 변경 개수, Ctrl+Z / Ctrl+Y.
  - 편집 중인 값은 `.bfview.json`에 함께 저장되어 다음에 이어서 고칠 수 있습니다.
- **내보내기** — 변경분 CLI 파일(Betaflight App CLI 탭에 붙여 넣기), 편집을 반영한 전체 diff.
- **기체에 쓰기** — 안전 확인 → 다시 읽어 같은 펌웨어·보드인지 확인 → 충돌이면 묻기 → 자동 백업 → 변경 목록·명령 미리보기와 기체 이름 입력 → **변경분만** 전송 → save → 다시 읽어 재검증.
  - 한 줄이라도 오류가 나면 save 없이 멈춥니다(기체를 다시 꽂으면 원래 설정).
  - 모터·보드 방향·수신기·시동 스위치·페일세이프·필터 값에는 경고를 붙입니다.
  - **백업으로 되돌리기**: 쓰기 직전과 다른 값만 같은 절차로 되돌립니다(`defaults` 초기화는 쓰지 않음).
  - **이 내용으로 기체 맞추기**: 저장해 둔 파일(기체 없이 고친 값 포함)을 열고 기체를 연결하면, 파일과 다른 값만 같은 절차로 써서 맞춥니다. 펌웨어 빌드·보드가 파일과 같아야 합니다.
  - 백업은 저장 폴더의 `backups\`, 송수신 원문 로그는 `logs\write_<날짜>.log`.
- 쓰기 지원 펌웨어: **4.5.x, 2025.12.x, 2026.6.x**. 그 밖은 막습니다.
- 편집 중에도 레이트는 보기와 같은 Actual 단위(°/s · 엑스포)로 고칩니다.
- 기체를 읽은 뒤 USB를 다시 꽂지 않아도 바로 쓸 수 있습니다(기체가 CLI 모드에 남아 있어도 들어감).

## 바뀐 점

- 읽기 명령에 `get`(인수 없음, 설정별 범위·허용값)이 추가되었습니다. 여전히 기체 설정을 바꾸지 않는 읽기 명령입니다.
- 저장 파일 형식 2(`schemaVersion: 2`). v1 파일도 열리지만, 범위 정보가 없어 편집하려면 기체를 한 번 다시 읽어야 합니다.
- `diff all` / `dump all` 읽기는 끝의 `save` 줄까지 기다립니다(주석 줄에서 잘리지 않게).

## 알아 둘 점

- 펌웨어가 저장하면서 다른 설정에 맞춰 값을 고치는 경우가 있습니다(예: 노치 주파수가 컷오프보다 낮으면 꺼짐). 그러면 결과 화면에 "다시 읽은 값이 다릅니다" 목록이 나옵니다.
- 2025.12 이상은 펌웨어에 빌드되지 않은 기능(`feature`)을 켜려 하면 `Unavailable` 로 답합니다. 앱은 이를 오류로 보고 save 없이 멈춥니다.
- 4.5.4 이상은 `save noreboot` 뒤 같은 연결에서 재검증하고, 끝나면 USB를 다시 꽂으라고 안내합니다. 4.5.3은 save 때 재부팅해서 앱이 다시 연결합니다(최대 15초). 재부팅으로 저장 응답이 끊겨도 다시 연결해 재검증합니다.
- LED, VTX 테이블, 서보, resource/timer/dma 는 보기만 됩니다.
